# Éditeur de fichiers (PWA)

## Mise en ligne sur GitHub Pages
1. Crée un dépôt GitHub (public), puis **Add file → Upload files** et glisse **tous** les fichiers de ce dossier à la racine.
2. **Settings → Pages → Deploy from a branch → main / (root) → Save**.
3. Après ~1 minute, l'adresse est `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`.

## Installation sur iPhone
1. Ouvre l'adresse **dans Safari**.
2. Bouton Partager → **Sur l'écran d'accueil** → Ajouter.
3. Lance l'app depuis l'icône : plein écran, fonctionne hors ligne.

Les mises à jour (nouveau `index.html` envoyé sur GitHub) arrivent automatiquement au lancement suivant avec réseau.
